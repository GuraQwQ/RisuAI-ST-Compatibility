RisuAI Windows x64 的第三方 SillyTavern 兼容补偿层实验版。

- 提供原生聊天桥接、角色卡预览与导入、ST 正则与世界书、MVU 变量算法及前端面板接口子集。
- 使用本项目的独立 DLL 启动运行层，安装后直接启动目标 RisuAI.exe；提供安装记录、重复安装与卸载恢复。
- Windows x64 ZIP 包含源码、许可与预编译 DLL；解压后按 README 使用 PowerShell 7 安装。另需 Node.js 22.12+、Python 3，安装依赖需要联网。

已验证 RisuAI 2026.10.220。接线使用内部接口，客户端更新可能需要适配；安装会增加 EXE 的 DLL 导入并改变文件哈希。真实模型、流式、群聊和完整外部扩展组合尚未完成验收，详情见兼容说明。
