RisuAI Windows x64 的第三方 SillyTavern 兼容补偿层 v0.3.0 实验版。

- 导入 ST Chat Completion 预设，按兼容角色保存编排组合、条目开关和附带正则；独立世界书支持导入、多选和重复复用。
- 接入 ST 实验宏引擎，支持 Nemo Engine 使用的嵌套块宏、变量与字典读取。
- 普通文本使用当前 RisuAI 的 Markdown 渲染；模型、采样设置及原生脚本、触发器、宏函数继续由 RisuAI 处理。
- 修复插件设置页透明背景、搜索条目隐藏失效，以及响应式对象跨窗口和 CDP 传输时的克隆、数组错误。
- README 增加三套预设、两张角色卡与两本内置世界书的验证清单、文件指纹和对照范围。测试、资源样本与报告由开发环境单独保存。

已验证 RisuAI 2026.10.220 / Windows x64。三套预设的 6 个配置场景、五组资源的正则样例和两本世界书扫描结果与原版 ST 对照一致，验收未调用模型 API。真实模型、流式、群聊及完整外部扩展组合仍需验证，详情见兼容说明。

ZIP 包含源码、许可与预编译独立加载器 DLL；按 README 使用 PowerShell 7 安装，另需 Node.js 22.12+、Python 3。安装会增加目标 EXE 的 DLL 导入并改变文件哈希；客户端更新后可重复执行安装，内部接口变化时可能需要适配。
