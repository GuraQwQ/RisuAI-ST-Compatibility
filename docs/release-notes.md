RisuAI Windows x64 的第三方 SillyTavern 兼容补偿层 v0.4.0 实验版。

- 接通 ST-Prompt-Template 固定版本的异步 EJS、helper、变量作用域、世界书 include、扫描与生成 loader、注入和渲染阶段；永久正文与后续重绘分别处理。
- 扩展 `TavernHelper` 命名空间，支持世界书、角色、玩家角色、预设、正则、文件与聊天结构读写；资源绑定和旧数据迁移可重复执行。
- 独立生成支持 raw 提示词顺序、覆盖历史、图片与注入；自定义 HTTP 连接支持 OpenAI 兼容协议、Claude 和 Gemini 的流式、工具、结构化输出与取消。
- 接通脚本库、共享运行库、Slash 管道与原生生命周期事件；原生停止按钮可以停止前端发起的非静默生成。
- 修复资源读取触发持续重绘、角色切换残留旧面板，以及浏览器依赖的生产构建参数。README 增加两个扩展固定提交的验证清单。

最新实机验证为 RisuAI 2026.10.292 / Windows x64。2026-11-01 完成资源读写、异步模板、raw 请求、本机流式与取消、原生固定回复和两张大型卡面板复验；五个原角色聊天、候选变量、模型采样与插件参数按基线保持一致。Node 回归 132 项、加载器回归 10 项通过。真实远程模型、群聊和任意外部扩展组合仍需分别验证，详情见兼容说明。

ZIP 包含源码、许可与预编译独立加载器 DLL；按 README 使用 PowerShell 7 安装，另需 Node.js 22.12+、Python 3。安装会增加目标 EXE 的 DLL 导入并改变文件哈希；客户端更新后可重复执行安装，内部接口变化时可能需要适配。
